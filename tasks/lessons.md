# Lessons learned

## 2026-10-27 — Requisitos de idioma y contexto visual

- En productos educativos, confirmar y reflejar desde el primer plan todos los idiomas de interfaz y contenido, indicando cuál es el predeterminado y cómo se conserva la elección.
- Cuando se soliciten imágenes para contextualizar actividades, definir antes de implementar su propósito pedagógico, accesibilidad, propiedad/licencia, rendimiento y la regla de que no deben revelar los datos necesarios para resolver el ejercicio.

## 2026-10-27 — Razonamiento con cálculos en papel

- En herramientas educativas, no mostrar automáticamente resultados ni pasos intermedios calculados si el objetivo es que el alumno haga las cuentas. La aplicación debe ofrecer representaciones y consignas para trasladar el razonamiento al papel, y reservar la comprobación para una acción expresa del alumno.

## 2026-10-27 — Operaciones apropiadas para el curso

- Cuando el alumnado aún no haya trabajado una operación formal, evitar su notación en herramientas, pistas y soluciones. Explicar los repartos con grupos iguales, sumas repetidas y multiplicaciones con una incógnita; conservar la comprobación matemática interna sin exponer esa operación.
